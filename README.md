# CFS_publico · Manual de Confirmsign

El único manual de estilos y piezas de Confirmsign. Sale del de Tatanka (nexoTTK), que es el bueno; Madre y los demás entornos se igualan a él.

- `manual/estilos/cfs-tokens.css`: los valores (colores, letras, medidas, radios, sombras), sacados del Sketch «Tatanka_26 V2.0 UX». No se edita a mano.
- `manual/estilos/cfs-componentes.css`: las piezas del sistema (botón, campo, selector, casilla, chip, acento, carrusel, tarjeta), las mismas del nexo.
- `manual/`: el escaparate, publicado en https://www.m-cfs.us/manual/

Letras: Poppins y Syne, con licencia SIL Open Font License (ver `manual/estilos/fonts`).
